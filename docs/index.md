# TaskFlow Internal Developer Portal

Welcome to the TaskFlow IDP — the single place to discover services, understand how the platform fits together, and provision new infrastructure through golden paths.

## What you'll find here

- **Software Catalog** — every TaskFlow component, system, and resource in one graph.
- **TechDocs** — documentation lives next to the code and is rendered here automatically.
- **Golden-path templates** — scaffold new services and infrastructure with production defaults baked in.

## Platform at a glance

TaskFlow runs on Amazon EKS with a GitOps delivery model (ArgoCD), multi-environment promotion (dev → staging → prod), and policy-gated CI/CD. This portal indexes all of it.
